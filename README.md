# Vynexa Stars
ربات مستقل فارسی برای فروش دستی استارز و پریمیوم.

## FadeHost
- Install command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- مقادیر `.env.example` را در Environment Variables وارد کن.
- `ADMIN_IDS` شناسه عددی تلگرام مدیر است.
- قیمت صفر یعنی محصول غیرفعال است؛ قیمت‌ها و اطلاعات کارت را تنظیم کن.
- توکن واقعی را در GitHub قرار نده.
- تحویل خودکار در این نسخه وجود ندارد؛ مدیر پس از تحویل واقعی، وضعیت سفارش را ثبت می‌کند.
- SQLite به دیسک پایدار روی هاست نیاز دارد.
