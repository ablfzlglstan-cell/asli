Vynexa Stars — نسخه با انتخاب تعداد دلخواه استارز

تغییرات:
- افزودن دکمه «🔢 انتخاب تعداد دلخواه» در منوی خرید استارز.
- کاربر تعداد دلخواه از ۱ تا ۱۰٬۰۰۰ را وارد می‌کند.
- مبلغ بر اساس قیمت بسته‌های موجود استارز محاسبه می‌شود؛ بین بسته‌ها درون‌یابی خطی انجام می‌شود و بالاتر از ۱۰۰۰ استارز، نرخ هر استارزِ بسته ۱۰۰۰تایی مبناست.
- قیمت بسته‌ها همچنان از سازوکار فعلی نرخ TON استفاده می‌کند.
- واکنش مثبت 👍 برای پیام کاربر در چت خصوصی و پیام‌های ربات هنگام تعامل با دکمه‌ها اضافه شده است. ثبت واکنش به اجازه‌ها و محدودیت‌های Telegram Bot API بستگی دارد.
- دکمه‌های «🎁 گیفت تلگرام» و «🚀 بوست چنل» حفظ شده‌اند.

نصب:
1) فایل bot.py و requirements.txt را در ریشه همان مخزن GitHub جایگزین کنید.
2) Commit و سپس همان اپ موجود FadeHost را Redeploy/Restart کنید.
3) متغیرهای محیطی قبلی را حفظ کنید؛ به‌ویژه BOT_TOKEN، ADMIN_IDS و قیمت‌های PRICE_STARS_50، PRICE_STARS_100، PRICE_STARS_250، PRICE_STARS_500، PRICE_STARS_1000.

نکته:
- این نسخه از قیمت‌های فعلی بسته‌ها برای محاسبه تعداد دلخواه استفاده می‌کند. اگر قیمت‌های بسته‌ها تنظیم نشده یا صفر باشند، مدیر باید آن‌ها را از پنل مدیریت تنظیم کند.
- تست سینتکس Python انجام شده؛ اجرای زنده با توکن و دیتابیس هاست شما انجام نشده است.
