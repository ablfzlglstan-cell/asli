Vynexa Stars — بسته بازسازی‌شده

محتویات:
- bot.py: سورس ربات با دکمه‌های «🎁 گیفت تلگرام» و «🚀 بوست چنل»، واکنش تصادفی مثبت در چت خصوصی و محاسبه قیمت بر اساس نرخ TON در صورت دریافت موفق نرخ.
- requirements.txt: وابستگی‌های ربات.
- README_FA.txt: راهنمای نصب.

نصب روی GitHub / FadeHost:
1) ZIP را استخراج کن.
2) در همان مخزن GitHub قبلی، bot.py را با فایل bot.py این بسته جایگزین کن. فایل باید در ریشه مخزن باشد.
3) requirements.txt را هم جایگزین کن.
4) Commit changes بزن.
5) در FadeHost همان برنامه قبلی را Redeploy/Restart کن. حساب یا برنامه قبلی را حذف نکن.
6) در Environment Variables هاست مطمئن شو BOT_TOKEN و ADMIN_IDS تنظیم شده‌اند. توکن را داخل سورس یا چت نفرست.

بررسی بعد از استقرار:
- در تلگرام /start را بزن؛ هر دو دکمه گیفت و بوست باید در منوی اصلی دیده شوند.
- با حساب کاربری عادی یک پیام متنی به ربات بفرست؛ ربات تلاش می‌کند واکنش تصادفی مثبت بگذارد. واکنش‌ها فقط برای چت خصوصی تنظیم شده‌اند و ممکن است بر اساس دسترسی‌های Bot API ناموفق شوند.
- قیمت TON فقط وقتی زنده به‌روزرسانی می‌شود که منبع نرخ عمومی در دسترس باشد و پاسخ قابل‌خواندن برگرداند؛ اگر نرخ دریافت نشود، قیمت پایه تنظیم‌شده نمایش داده می‌شود. برای تأیید نهایی، لاگ‌های FadeHost را بررسی کن.

مهم: ZIP به‌تنهایی نسخه میزبانی‌شده را تغییر نمی‌دهد. باید فایل‌ها را در مخزن درست جایگزین و برنامه همان مخزن را دوباره Deploy کنی. اگر در مخزن اشتباه Commit شود، هیچ تغییری در ربات آنلاین نمی‌بینی.
