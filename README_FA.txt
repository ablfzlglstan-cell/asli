Vynexa Stars - نسخه دارای نرخ لحظه‌ای TON از Swap Wallet

نصب:
1) فایل bot.py را در مخزن GitHub جایگزین نسخه قبلی کنید.
2) Commit changes را بزنید.
3) در FadeHost برنامه را Restart کنید.
4) در Environment Variables مطمئن شوید BOT_TOKEN و ADMIN_IDS تنظیم شده‌اند.

قیمت‌ها:
پنل مدیریت > ویرایش قیمت > انتخاب محصول > مبلغ تومان > تأیید و ذخیره.
قیمت پایه هر محصول همچنان مبلغ تومانی تعیین‌شده توسط مدیر است. هنگام انتخاب محصول، ربات نرخ TON را از API عمومی قیمت Swap Wallet می‌خواند و معادل تقریبی TON را نشان می‌دهد. نرخ برای ۶۰ ثانیه cache می‌شود تا ربات کند نشود. API عمومی قیمت نیاز به API key ندارد.

نکته:
این تغییر نرخ بازار TON و معادل آن را نمایش می‌دهد؛ پرداخت واقعی با TON یا اجرای خرید/سواپ از حساب Swap Wallet در این نسخه فعال نشده است.

ایموجی‌ها:
از پنل مدیریت گزینه «تغییر ایموجی دکمه‌ها» را انتخاب کنید و سپس دکمه موردنظر و ایموجی را بفرستید.

راهنما:
دستور /help راهنمای جداگانه نمایش می‌دهد.
