FOX REPORTER — نسخه امن و پایه

این فایل‌ها یک ربات دریافت گزارش می‌سازند:
- /start: نمایش منو
- ثبت گزارش متنی
- ذخیره گزارش‌ها در SQLite
- ارسال گزارش به مدیر ربات

محدودیت مهم:
کدی که در پیام قبلی فرستاده شد ناقص بود؛ بنابراین این پروژه بازسازی همان سورس اصلی نیست.
این نسخه عمداً از ورود به حساب‌های کاربری، شماره تلفن، api_hash، session_string،
دریافت کد ورود یا گزارش‌دهی خودکار/انبوه استفاده نمی‌کند.

راه‌اندازی در Termux (Android)
1) نصب Termux را از منبع معتبر و به‌روز انجام بده.
2) ترموکس را باز کن و این دستورات را یکی‌یکی اجرا کن:

pkg update && pkg upgrade -y
pkg install python nano -y
mkdir -p ~/fox_reporter
cd ~/fox_reporter

3) فایل‌های ZIP را در گوشی استخراج کن و پوشه پروژه را به ~/fox_reporter منتقل کن.
   اگر ZIP را در Downloads گذاشتی، ابتدا دسترسی فایل را بده:
   termux-setup-storage
   سپس می‌توانی فایل را از مسیر ~/storage/downloads کپی کنی.

4) کتابخانه‌ها:
python -m pip install --upgrade pip
pip install -r requirements.txt

5) تنظیم توکن و شناسه مدیر:
nano config.env.example
مقادیر نمونه را با اطلاعات خودت جایگزین کن و فایل را با نام .env ذخیره کن.
برای ذخیره در nano: Ctrl+O، Enter، سپس Ctrl+X.
(اگر فایل .env را نمی‌بینی، دستور `ls -la` را اجرا کن.)

6) نصب بارگذار متغیرهای محیطی:
pip install python-dotenv
سپس ابتدای bot.py، بعد از import os، این دو خط را اضافه کن:
from dotenv import load_dotenv
load_dotenv()

7) اجرا:
python bot.py

برای توقف:
Ctrl+C

نکته‌ها:
- ترموکس تا وقتی فرایند اجراست باید باز بماند؛ برای اجرای پایدارتر می‌توانی از
  ابزارهای مدیریت نشست ترموکس استفاده کنی، اما این نسخه برای میزبانی ۲۴ساعته
  بهتر است روی سرور قابل‌اعتماد اجرا شود.
- توکن ربات را محرمانه نگه دار. اگر افشا شد، از BotFather آن را باطل و دوباره صادر کن.
- گزارش‌ها در فایل fox_reporter.db ذخیره می‌شوند.
- هرگز کد ورود، رمز دومرحله‌ای یا session string افراد را دریافت یا ذخیره نکن.
