Vynexa Stars - نسخه اصلاح‌شده

نصب/به‌روزرسانی:
1) فایل bot.py را در مخزن GitHub جایگزین فایل قبلی کنید.
2) Commit changes را بزنید.
3) در FadeHost برنامه را Restart کنید.
4) در Environment Variables مطمئن شوید BOT_TOKEN و ADMIN_IDS تنظیم شده‌اند.
5) نسخه python-telegram-bot باید 22.7 یا جدیدتر باشد (برای icon_custom_emoji_id).

تنظیم قیمت:
پنل مدیریت > ویرایش قیمت > انتخاب محصول > ارسال مبلغ به تومان > تأیید و ذخیره.

ایموجی سفارشی برای دکمه‌ها:
1) مدیر در چت خصوصی ربات دستور /emoji را بفرستد.
2) دکمه‌ای را انتخاب کند.
3) خودِ custom emoji تلگرام را به‌صورت پیام ارسال کند.
4) برای هر دکمه دیگر این مراحل را تکرار کند.

نکته مهم: قابلیت icon_custom_emoji_id در Bot API به Premium فعال برای مالک ربات یا شرایط مجاز Fragment نیاز دارد؛ صرفاً Premium بودن حسابی که با آن ایموجی را می‌فرستد، به‌تنهایی تضمین‌کننده نمایش در دکمه نیست. اگر تلگرام اجازه استفاده به خود ربات ندهد، API هنگام ویرایش/ارسال کیبورد خطا می‌دهد.

راهنما:
دستور /help راهنمای جداگانه نمایش می‌دهد.

Swap Wallet:
اتصال واقعی به API سواپ‌ولت و نرخ لحظه‌ای TON در این نسخه پیاده‌سازی نشده است. برای اضافه‌کردن آن باید endpoint رسمی نرخ و روش احراز هویت مستندات API تأیید شود. کلید API را داخل چت یا داخل فایل عمومی GitHub قرار ندهید؛ در Environment Variables هاست ذخیره کنید.
