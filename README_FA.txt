Vynexa Stars — بسته آماده برای GitHub / FadeHost

محتویات این ZIP دقیقاً سه فایل است:
1) bot.py — سورس ربات با دکمه‌های گیفت و بوست، واکنش خودکار در چت خصوصی و محاسبه قیمت بر اساس نرخ TON دریافت‌شده.
2) requirements.txt — وابستگی‌های لازم.
3) README_FA.txt — همین راهنما.

نصب/به‌روزرسانی:
1. ZIP را روی گوشی استخراج کن.
2. در مخزن GitHub همان ربات، فایل bot.py را با bot.py داخل ZIP جایگزین کن؛ فایل را با نام bot.py و در ریشه مخزن قرار بده.
3. requirements.txt را هم جایگزین کن.
4. Commit changes را بزن.
5. در FadeHost همان برنامه قبلی را باز کن و Restart/Redeploy بزن. برنامه/حساب قبلی را حذف نکن.
6. در Environment Variables هاست، BOT_TOKEN و ADMIN_IDS باید تنظیم باشند. مقادیر محرمانه را در فایل یا چت عمومی قرار نده.

تست پس از استقرار:
- /start را بزن؛ دکمه‌های «🎁 گیفت تلگرام» و «🚀 بوست چنل» باید در منو باشند و هشدار آماده‌نبودن نشان بدهند.
- به ربات در چت خصوصی یک پیام متنی بفرست؛ ربات تلاش می‌کند یک واکنش مثبت تصادفی ثبت کند. در گروه‌ها واکنش نمی‌گذارد. پشتیبانی این قابلیت به تنظیمات/نسخه Bot API تلگرام وابسته است.
- در پنل مدیریت قیمت یک محصول را ذخیره کن. نرخ TON از منبع عمومی تعریف‌شده در کد دریافت می‌شود و قیمت با نسبت نرخ جدید به نرخ مرجع زمان ذخیره قیمت تغییر می‌کند. اگر منبع قیمت در دسترس نباشد، قیمت پایه نمایش داده می‌شود؛ پس نرخ زنده باید در لاگ‌های FadeHost هم بررسی شود.

نکته: ساخت ZIP به‌تنهایی ربات میزبانی‌شده را تغییر نمی‌دهد؛ باید فایل‌ها را واقعاً در GitHub جایگزین و برنامه موجود را Redeploy/Restart کنی.
