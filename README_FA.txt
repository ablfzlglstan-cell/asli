Vynexa Stars — راهنمای نصب

محتویات:
- bot.py: کد ربات
- requirements.txt: وابستگی‌ها
- README_FA.txt: همین راهنما

تنظیمات هاست (Environment Variables):
- BOT_TOKEN: توکن ربات از BotFather
- ADMIN_IDS: آیدی عددی مدیرها، با کاما جدا شوند
- PRICE_PREMIUM_3M / PRICE_PREMIUM_6M / PRICE_PREMIUM_12M: قیمت پایه پریمیوم به تومان
- PRICE_STARS_50 / PRICE_STARS_100 / PRICE_STARS_250 / PRICE_STARS_500 / PRICE_STARS_1000: قیمت پایه استارز به تومان
- CARD_NUMBER و CARD_HOLDER: اطلاعات کارت پرداخت

نرخ TON:
کد تلاش می‌کند قیمت TON را از CoinGecko دریافت کند. قیمت IRR ریال است و برای نمایش تومان بر ۱۰ تقسیم می‌شود. اگر API در دسترس نباشد، قیمت پایه مدیر نشان داده می‌شود؛ در این وضعیت قیمت زنده تضمین‌شده نیست.

قیمت پایه‌ای که مدیر تنظیم می‌کند در نرخ فعلی TON ثبت می‌شود و با تغییر نرخ دریافتی، قیمت محصول به نسبت تغییر می‌کند. نرخ در حافظه به مدت ۶۰ ثانیه cache می‌شود.

واکنش خودکار فقط برای پیام‌های چت خصوصی فعال است؛ خطاهای محدودیت یا عدم پشتیبانی تلگرام نادیده گرفته می‌شوند.

برای نصب، سه فایل را در ریشه مخزن GitHub قرار دهید و همان برنامه موجود را در هاست redeploy کنید. برنامه یا مخزن قدیمی را حذف نکنید. توکن را داخل کد ننویسید؛ فقط در Environment Variables قرار دهید.
