Vynexa Stars - نسخه اصلاح‌شده

1) فایل bot.py را در مخزن GitHub جایگزین فایل قبلی bot.py کنید.
2) Commit changes را بزنید.
3) در FadeHost برنامه را Restart کنید.
4) در Environment Variables مطمئن شوید BOT_TOKEN و ADMIN_IDS تنظیم شده‌اند.

تنظیم قیمت:
پنل مدیریت > ویرایش قیمت > انتخاب محصول > ارسال مبلغ به تومان > تأیید و ذخیره.

راهنما:
دستور /help راهنمای جداگانه نمایش می‌دهد.

نکته مهم:
اتصال واقعی به API سواپ‌ولت و نرخ لحظه‌ای TON هنوز در این نسخه پیاده‌سازی نشده، چون آدرس مستندات/endpoint رسمی همان API مشخص نیست. API key به‌تنهایی برای ساخت اتصال امن و درست کافی نیست. کلید API را داخل چت ارسال نکنید.
